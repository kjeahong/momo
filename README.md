# Momo (모모) 🧠

> **"어디에 어떤 키워드로 적었든, 글과 이미지까지 전부 기억해 찾아주는 제2의 두뇌 메모앱"**  
> Joplin의 친숙함과 안정성을 계승하고, **한글 완벽 검색(Trigram FTS5)** 및 **온디바이스 이미지 OCR 검색**을 탑재한 차세대 로컬 퍼스트 마크다운 메모앱

---

## ✨ 왜 Momo인가요?

수년간 메모를 수천 개씩 쌓다 보면 다음과 같은 치명적인 한계에 부딪힙니다:
1. **조사 하나 때문에 검색이 안 됨**: "회의록에서", "보고서를"이라고 적어두면 "회의", "보고서"로 검색해도 안 나오는 현상
2. **이미지/스크린샷은 검색 불가능**: 캡처해서 붙여넣은 중요한 정보들이 검색 인덱스에서 누락되어 잊혀짐
3. **새로운 메모 앱(옵시디언, 노션)의 높은 진입장벽**: 적응하기 어렵고, 데이터 이전이 복잡하며, 러닝 커브가 높음

**Momo**는 Joplin의 검증된 3단 레이아웃(노트북 - 리스트 - 에디터)을 유지하여 **학습 비용 0%**를 제공하면서, **어디에 어떻게 저장했든 1초 만에 찾아내는 압도적인 검색 성능**을 제공합니다.

---

## 🚀 주요 기능

- 📁 **익숙한 3단 UI 레이아웃**: 노트북/폴더 트리, 노트 리스트, 실시간 마크다운 에디터 & 프리뷰
- ⚡ **한국어 완벽 하이브리드 검색**:
  - SQLite FTS5 Trigram + Substring LIKE 하이브리드 인덱싱
  - 2글자 단어(`회의`, `예산`), 복합어, 조사 결합 단어까지 100% 부분일치 검색
- 👁️ **온디바이스 이미지 OCR 검색**:
  - 붙여넣은 스크린샷/사진 속 텍스트를 로컬에서 자동 인식하여 검색 색인에 즉시 반영
  - 인터넷 연결 없이 100% 로컬에서 안전하고 프라이빗하게 처리
- 🔄 **1클릭 Joplin 데이터 마이그레이션**:
  - 기존 Joplin SQLite DB 및 첨부 이미지를 클릭 한 번으로 무손실 가져오기
- 📦 **배포 가능한 단독 실행 파일**:
  - 설치형/무설치형(`.exe`) 패키징 지원

---

## 🛠️ 기술 스택

- **Runtime**: Electron / Node.js
- **Frontend**: Vite + React 19 + TypeScript + Tailwind CSS
- **Database & Search**: SQLite 3 (FTS5 Trigram Virtual Table)
- **OCR Engine**: Local On-device OCR Pipeline
- **Markdown**: GFM (GitHub Flavored Markdown) Renderer & Editor
